# RQ2 Results

This directory contains the final corrected LatestFail results used for RQ2.

The files beginning with `LatestFail_FINAL` contain the authoritative LatestFail results used in the final thesis.

The files beginning with `LatestFail_ORIGINAL` contain the pre-correction LatestFail results and are retained only for audit and comparison.

`LatestFail_original_vs_corrected_global_summary.csv` shows the effect of the correction at each tested noise level.

`LatestFail_correction_scope.csv` identifies the 14 projects for which the LatestFail handling was corrected and the 10 legacy projects that were unchanged.

`LATESTFAIL_GLOBAL_CORRECTION_MANIFEST.json` records the final row counts, project counts, aggregation procedure, and SHA-256 checksums for the correction package.

The final RQ2 analysis uses the corrected LatestFail results only.
